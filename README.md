# 옥상일지 · 우리의 동네

좀비 아포칼립스 이후의 서울. 가족과 친구의 흔적을 찾아 옥상으로 데려오고, 여러 건물의 지붕을 연결해 살아가는 PC 웹 생존 게임입니다. 메인 이야기는 재회와 정착으로 이어지며, 완료 뒤에도 생활이 계속됩니다.

## 실행

Node.js가 설치된 환경에서 `npm run dev` 후 `http://127.0.0.1:4173/`을 엽니다. Windows에서는 `start-game.ps1`로도 실행할 수 있습니다. 의존성 설치는 필요하지 않습니다. Three.js 0.180.0을 `vendor/`에 포함해 외부 CDN 없이 실행합니다.

`npm test`로 시뮬레이션과 음악·패널 동작을 검증하고, `npm run build`로 정적 호스팅용 `dist/`를 만듭니다. 저장은 서버 계정이 아닌 브라우저별로 유지됩니다.

## 시간과 생존

- 평상시에는 현실 1초 = 게임 1분입니다. 옥상을 바라보며 머물 수 있습니다.
- 행동 중에는 현실 1초 = 게임 12분이며, 1·2·4배속은 행동에만 적용됩니다. 행동이 끝나면 바로 평상시 속도로 돌아옵니다.
- 사건·결과·안내를 읽거나 탭을 숨기고 게임을 닫으면 진행하지 않습니다.
- 생산과 소비는 시간에 따라 계산됩니다. 주민과 개는 물자를 소비하며, 기본 시설만으로는 이웃이 늘어나는 소비를 감당할 수 없습니다.
- 하루 생산·소비·순수지와 남은 비축 일수를 상태창에서 확인할 수 있습니다.

## 탐색에서 정착으로

모든 건물의 수색 한도는 **층수 × 3**입니다. 식수 수색도 같은 한도를 사용합니다. 각 건물의 2~3마리 좀비는 전투·유인·우회 등 장비와 기술에 따른 선택으로 해결합니다. 이미 수색한 곳에서 물자가 무한히 나오지 않습니다.

건물의 단서는 가족·친구를 찾는 이야기와 새 경로로 이어집니다. 수색과 위험 처리가 끝난 건물의 옥상을 확보하면 그곳에 설비를 짓고 주민을 배치할 수 있습니다. 주민은 휴식·작물·식수·경계를 나누며, 강화한 설비와 인력으로 자급 체계를 만듭니다.

설비에는 개선 단계와 기술 조건이 있습니다. 기초 시설, 전력과 작업 설비, 주민의 역할을 차례로 갖춰야 합니다. 창고 한도, 보존과 유지 비용도 고려해야 하므로 초반의 물자 확보와 후반의 자동화가 다른 과제가 됩니다.

## 풍경과 소리

새 게임마다 옥상 구조·층수·도시 배치가 달라지고 같은 저장에서는 유지됩니다. 랜턴과 전구, 작은 생활 도구와 바닥, 보리와 주민의 움직임이 동네의 변화를 보여줍니다. 드래그로 풍경을 회전하고 휠로 거리를 조절합니다. H로 UI를 숨길 수 있습니다.

상단 ♫는 오리지널 로파이 **옥상에 남은 오후**를 켭니다. 76 BPM의 건반·베이스·스윙 드럼이며 외부 곡이나 녹음 샘플을 사용하지 않습니다. 환경음은 스피커 버튼으로 따로 조절하고 옆 슬라이더로 음량을 정합니다. 음악과 환경음 모두 클릭한 뒤에만 시작합니다. [음악 사용 조건](MUSIC-LICENSE.md).

## 창 배치

상태창·오늘의 기록·행동 창은 전용 이동 손잡이와 모서리 크기 조절 손잡이를 제공합니다. 변경한 배치는 브라우저에 별도로 저장됩니다. 상단 ↺ 버튼으로 기본 배치를 복원합니다. Space는 일시정지, 1·2·3은 행동 배속을 조절합니다.

## 구성

- `src/game.js`, `src/content.js`: 시간·자원·탐색·전투·주민·사건·자동화·저장 이전.
- `src/app.js`: 화면, 선택 결과, 브라우저 저장, 주민 배치.
- `src/scene.js`: 반복 오브젝트 인스턴싱을 사용한 도시와 생활 연출.
- `src/audio.js`: 오리지널 로파이 스코어와 실시간 소리 합성.
- `src/panels.js`, `panel-layout.css`: 창 이동·크기 조절·배치 복원.
- `tests/`: 핵심 규칙과 진행 검증, 개발 전용 시각 확인 도구. 배포에는 포함하지 않습니다.
