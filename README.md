# 옥상일지

좀비 아포칼립스 이후의 서울. 작은 아파트 옥상을 가꾸고, 물자를 관리하며, 다른 생존자와의 관계 속에서 다음 날을 만드는 PC 웹 생존 게임입니다.

## 실행

Node.js가 설치된 환경에서:

```sh
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 의존성 설치는 필요하지 않습니다. Three.js 0.180.0을 `vendor/`에 포함했으며 외부 CDN 없이 실행됩니다. Windows에서는 `start-game.ps1`로도 실행할 수 있습니다.

```sh
npm test
npm run build
```

`dist/`는 정적 호스팅용 결과물입니다. 로컬 저장 데이터는 서버가 아닌 브라우저에 남습니다.

## 플레이

- 현실 4분 = 게임 하루. 1·2·4배속을 지원합니다.
- 선택지, 선택 결과, 도움말, 이야기 일지를 읽는 동안에는 정지합니다.
- 탭이 숨겨졌거나 게임을 닫은 동안에는 진행되지 않습니다.
- 아래층 탐색, 물 확보, 휴식과 치료로 버티고 빗물받이·텃밭·출입문·수신기를 준비합니다.
- 바깥 탐색은 학교·중계소·강변의 단서를 얻은 뒤 시작할 수 있습니다.
- 이야기 패널에서 다음 목표와 영구 능력, 단서를 확인할 수 있습니다.
- 새 게임마다 옥상 구조·높이·도시 배치가 달라집니다. 같은 저장 기록에서는 지형이 유지됩니다.
- Space: 일시정지 / 1·2·3: 배속 / H: 풍경만 보기. 드래그로 회전, 휠로 확대·축소합니다.

## 구성

- `src/game.js`: DOM과 분리된 결정론적 시뮬레이션, 사건 조건과 지연 결과, 저장 검증·마이그레이션.
- `src/content.js`: 오리지널 한국어 사건, 능력, 단서와 결말.
- `src/scene.js`: 외부 모델 없이 구성한 Three.js 도시·캠프, 낮밤·날씨·시설 변화.
- `src/app.js`: UI, 오프라인 정지, 자동 저장, 환경음.
- `tests/game.test.js`: 시간·소비·사건·저장과 실제 생존 과정의 엔딩 도달 검증.
- `tests/scene-profile.html`: 고정 시드의 렌더링 진단. 개발 서버에서만 이용합니다.

## 비주얼과 성능

도시와 캠프의 반복 오브젝트는 인스턴싱을 사용합니다. 건물 창문은 평면으로, 먼 건물은 상세 단계를 낮춰 그립니다. 태양 그림자는 캠프 중심으로 캐시하고 카메라 회전만으로 다시 계산하지 않습니다. 최고 렌더링 빈도는 60FPS이며 화면 해상도를 제한해 고주사율·고해상도 환경의 불필요한 GPU 부하를 줄입니다. 우측 상단의 그래픽 버튼에서 더 가벼운 설정을 선택할 수 있습니다.

개발 환경의 동일 시드·1280×720 장면 비교: 프레임당 삼각형 1,073,778 → 151,152(약 86% 감소). 기기별 실제 FPS를 보장하는 수치는 아니며, 같은 장면의 기하 부하 비교입니다.
